VERSE — BASIC UI BETA

Open index.html in your browser for a working UI preview.

Features: white lyrics, translucent album-colored background, collapsible
pill, glass tint slider, minimal play/pause and progress bar.
Sample songs switch automatically at the end of each demo track.
All sample songs and lyrics are fictional. Spotify is not connected yet.
Colors are preset for the sample covers; real artwork color extraction
will be added with the Spotify integration.

DESKTOP MODE
Requires Node.js and npm.
In this folder run:
  npm install
  npm start

Desktop mode has a transparent, frameless, always-on-top window in the
top-left corner. Drag its header to move it. Cmd/Ctrl+Shift+L hides or
shows the window. Quit through the app menu or stop the terminal process.
Fullscreen behavior can vary with the operating system.

No Spotify developer account or login is required for this demo.
