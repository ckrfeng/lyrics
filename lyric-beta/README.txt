VERSE — DESKTOP BETA

The prototype now includes Spotify PKCE onboarding, LRCLIB lyrics,
secure token storage, a menu-bar app, remembered window settings,
and the original fictional demo.

From the repository root:
  npm ci
  npm start

To force the fictional demo without loading Spotify credentials:
  npm run demo

Open index.html in a browser for a demo-only preview.
See ../README.md for setup, verification, policies, and limitations.
